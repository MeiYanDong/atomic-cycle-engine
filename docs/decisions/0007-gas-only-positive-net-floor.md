# ADR 0007：Base 实盘只保留 Gas 后正收益门槛

状态：Accepted

日期：2026-09-13

## 背景

Base watcher 原先在完整费用之外额外要求每笔至少净赚 `0.000005 WETH`，执行合约还保留了不可变的
`0.000001 WETH` 静态毛利底线。这两个固定额度都会先于完整 Gas 估算拒绝候选，因而无法严格证明系统只受
Gas 调整后正收益约束。用户明确要求用实盘回执验证，并把长期正收益而非固定单笔收益额作为约束。

## 决策

1. 把执行合约的 `minimumGrossProfit` 和 watcher 的额外 `minimumNetProfit` 都降为 `1 wei`。所有正毛利候选因此可以进入最新区块重报价与完整 Gas 估算，不再被固定收益额度提前拒绝。
2. 不降低真实成本门槛：Gas limit 继续按 120%、L1 fee 按 150%、operator fee 按 120% 放大，报价毛利只按 80% 计入。
3. 保留 `0.003 WETH` 单笔本金、`0.005 ETH` signer 储备、`0.001 ETH` 累计失败 Gas 熔断、两区块有效期、20 秒 deadline、完整执行器模拟和回执后经济对账。
4. 毛利为正但无法覆盖上述保守费用的路线仍不广播；这种拒绝不是 shadow 模式，而是实盘执行器的成交前风险门禁。为计算 Base L1 data fee，候选可能生成一次不会离开进程的本地签名序列化结果；只有完整门禁通过后才持久化计划并广播。

## 结果

- 通过完整成本门槛的最小正净利机会可以立即进入原子提交，不会因为固定 `0.000005 WETH` 净利或
  `0.000001 WETH` 毛利额度而错过。
- 竞争或状态变化仍可能造成回滚 Gas；该风险由报价折扣、短有效期和累计失败 Gas 熔断约束。
- watcher 的净利润底线只需修改运行时配置；执行合约的静态毛利底线是 immutable，因此必须先部署未启用的新合约，再按运行手册停止 watcher、迁移原有 WETH、启用新合约并读回。ABI、token allowlist 和资本上限不变。
