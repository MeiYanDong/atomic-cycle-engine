# ADR 0007：Base 实盘只保留 Gas 后正收益门槛

状态：Accepted

日期：2026-09-13

## 背景

Base watcher 原先在完整费用之外额外要求每笔至少净赚 `0.000005 WETH`。这会拒绝已经覆盖保守 Gas、L1 data
fee、operator fee 和报价衰减，但净利润小于固定额度的真实机会。用户明确要求用实盘回执验证，并把长期正收益而非固定单笔收益额作为约束。

## 决策

1. 把额外 `minimumNetProfit` 降为 `1 wei`，保证净值严格为正，但不再人为要求固定收益额度。
2. 不降低真实成本门槛：Gas limit 继续按 120%、L1 fee 按 150%、operator fee 按 120% 放大，报价毛利只按 80% 计入。
3. 保留 `0.003 WETH` 单笔本金、`0.005 ETH` signer 储备、`0.001 ETH` 累计失败 Gas 熔断、两区块有效期、20 秒 deadline、完整执行器模拟和回执后经济对账。
4. 毛利为正但无法覆盖上述保守费用的路线仍不签名、不广播；这种拒绝不是 shadow 模式，而是实盘执行器的成交前风险门禁。

## 结果

- 通过完整成本门槛的最小正净利机会可以立即进入原子提交，不会因为固定 `0.000005 WETH` 额度而错过。
- 竞争或状态变化仍可能造成回滚 Gas；该风险由报价折扣、短有效期和累计失败 Gas 熔断约束。
- 本次只改变运行时经济策略，不改变执行器 ABI、token allowlist、资金位置或资本上限，无需重新部署合约。
