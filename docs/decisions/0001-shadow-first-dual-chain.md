# ADR-0001：独立仓库、双链 Shadow-first

日期：2026-09-11

状态：Accepted

## 背景

现有 Robinhood Chain 服务具有真实资金、既有合约和生产运行历史。把任意协议、Base pending state 与通用路径直接塞进该服务，会同时扩大回归面、权限面和错误归因风险。

## 决策

建立独立 `atomic-cycle-engine` 仓库：

- Robinhood Chain 保留为已知机制与低流量市场样本；
- Base 作为第二条高活跃同链市场；
- 支持任意资产类别，但首期只支持 2–4 跳同链 AMM 闭环；
- discovery 广覆盖，execution 必须 typed/allowlisted；
- Phase 0/1/2 不接 signer，不广播，不部署；
- 只有满足技术规格中的量化晋级门槛并获得新授权，才创建自有资金 Canary。

## 后果

收益是生产隔离、来源清晰、适配器可逐个验证、机会全集可测。代价是短期不会因为“新增很多池”就立即产生实盘交易；机会密度、竞争和 RPC 投资价值要先用影子证据回答。

## 被否决方案

- 继续围绕 PAIR 扩池：市场边界错误，无法解决流量不足；
- 直接在现有实盘仓库泛化：回归与资金风险过大；
- 一开始上多链、CEX 和跨链：无法保持同笔原子结算，问题类型发生变化；
- 一开始使用闪电贷：放大执行复杂度，却没有先证明机会容量和可赢性。
